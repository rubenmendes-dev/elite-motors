# Elite Motors

A Elite Motors é um website fictício de um stand especializado na venda de automóveis desportivos e de luxo. Foi desenvolvido no âmbito de uma formação em programação Web, com o objetivo de aplicar conhecimentos de HTML5 e CSS3.

## Funcionalidades

- Catálogo com 12 automóveis desportivos e de luxo, incluindo fotografias e preços.
- Menu de navegação entre as principais secções do website.
- Formulário de pedido de informações com validação dos campos obrigatórios.
- Secção de contactos com email, telefone e localização.
- Design responsivo, adaptado a computadores, tablets e telemóveis.
- Efeitos visuais e transições para melhorar a experiência do utilizador.

## Tecnologias utilizadas

- **HTML5** - Estrutura e organização do website.
- **CSS3** - Estilização CSS Grid e responsividade.
- **Git** - Controlo de versões do projeto.
- **GitHub** - Publicação e alojamento do repositório.

## Como visualizar o projeto

1. Descarregar o repositório do GitHub.
2. Abrir a pasta do projeto no computador.
3. Abrir o ficheiro "elite-motors.html" num navegador Web.

Para visualizar corretamente o website, é necessário manter o ficheiro CSS e a pasta de imagens na estrutura original do projeto.
